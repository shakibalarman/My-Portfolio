## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- (Optional) A local server for better development experience

### Installation

1. Clone or download this repository
2. Navigate to the `Frontend` folder
3. Open `index.html` in your web browser

**For development:**
```bash
# If you have Python installed
python -m http.server 8000

# Or if you have Node.js
npx http-server
```

Then visit `http://localhost:8000` (or the port shown) in your browser.

The website is fully responsive and works seamlessly on:

## 🎨 Customization

To personalize this portfolio:

1. **Update Content**: Edit `Frontend/index.html` with your information
2. **Modify Styles**: Customize colors and layout in `Frontend/style.css`
3. **Add Interactivity**: Enhance features in `Frontend/script.js`
4. **Replace Images**: Update files in `Assets/images/`
5. **Update CV**: Replace the CV file in `Assets/cv/`
